BEFORE THE TECHNIQUES

Learn yourself first.

ACUMEN is built around a simple idea: techniques are tools, not identities. Before asking “Which method should I use?”, ask “What keeps happening when I try to learn?”

01 / NOTICE

What actually happens?

Where do you get stuck? Starting? Understanding? Remembering? Staying with a difficult task? The scan turns vague impressions into observable signals.

02 / QUESTION

What might explain it?

A profile is a hypothesis, not a verdict. Context matters, and the same person can behave differently across subjects, days and environments.

03 / TEST

What changes when you experiment?

Try one small intervention, observe what happens, then adjust. Self-knowledge becomes useful when it changes what you do.

KNOWN METHODS · PRACTICAL TECHNIQUES

ACUMEN draws on established learning and motivation mechanisms. None is a magic button, because apparently studying still requires the student.
